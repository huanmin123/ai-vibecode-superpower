# 深挖复审台账

台账是深挖环的唯一状态载体：登记脉络、假设、覆盖、扩散、修复与终报，跨会话续跑只依赖本文件。放目标项目文档惯例位置；无惯例时新建 `docs/plans/deep-dive-review-<对象>-<日期>.md`。

规模纪律：台账会被多轮追加，必须边走边压缩——每轮收口把该轮条目明细压缩为统计与指向问题记录文档的指针，只保留未收口条目的完整行。已证伪条目保留一行不删（终报复盘用），证据细节移入问题记录。

## 头部

```markdown
# 深挖复审台账：<对象>

- 锚定范围：<一句话>
- 发起：<日期>，<发起会话/人>；授权：<修复方式（含 A 类即修权声明）>
- 需求脉络：目标 / 非目标 / 可见行为
- 涉及文件：<初始清单>
- 关联契约：<文档 / API / 事件>
- 项目裁决出处：<AGENTS.md、docs/... 相关条目位置>
- 代码基线：<commit/分支 + 相关 diff 摘要>
- 工作区边界：<并行会话占用的域/文件、共享序号占用>
- 当前阶段 / 当前轮次：<阶段>；R<n>（视角：<视角>）
- 收敛计数：<连续干净轮数 / 需 3>
```

## 问题条目表（活跃条目）

只列未收口条目，5 列：

| ID | 来源 | 假设（一句话） | 关键依据 | 状态 |
| --- | --- | --- | --- | --- |

状态机：`假设 → 已确认 / 已证伪 / 待定 → A即修 / B过目 / C裁决 / 已裁决接受 / 待修 → 已修 → 已复核`。
已证伪条目保留一行（一句话+反证指针），证据细节移入问题记录文档。

## 覆盖矩阵（可选）

小对象（≤30 格）按轮画全矩阵，每格只接受"已查 + 未发现 + 理由"或"发现 → 编号"；空白视为未覆盖。大对象以"复核通过面"文字结论代替，每条结论必须带 file:line 依据，且注明本轮视角已覆盖的维度/场景/交互面清单。

| --- | --- | --- | --- |

收口时整表移交；已在更早轮次被裁决的行标注结论保留。

## 终报（收口时写）

- 终止原因：收敛终止（三条件满足）/ 用户裁决提前收口（如实说明收敛协议未走满）/ 中止（未完成）。
- 扫描范围与轮次（含各轮视角与假设/确认/证伪统计）。
- 处置统计：即修总数与分布、B 类批次、C 类裁决数、证伪数。
- 修复与验证证据摘要（指向各问题记录文档）。
- 移交清单：功能补齐类裁决 / 产品取舍类裁决 / 测试缺口登记 / 运维与部署义务 / 观察项。
- 未提交改动清单（按域分组，标注与其他会话的混合署名文件）。

# 对外资料

> 使用说明（复制后删除本段）：复制本文件到目标项目仓库根 `external/README.md`（与 `docs/` 平级）。本目录及其索引由项目维护者手工维护，AI 在日常开发中不读取、不检查、不主动更新。

## 目录定位

本目录保存面向外部使用者的交付资料：演示（HTML demo 等）、外部对接文档、模板与工具等。目标读者是外部用户，用于快速了解、对接和使用本系统，不是内部维护者的工作文档。

## 使用与维护边界

- 仅当用户明确要求维护对外资料时，AI 才读取或修改本目录；日常开发、修复、重构和内部文档同步均不检查本目录。
- 内容必须与系统实际行为一致。系统行为变化时由维护者决定是否同步对外资料，AI 不自动更新。
- 必须脱敏：不得包含凭据、私有环境事实、内部主机或账号、未发布计划和内部运行数据。
- 本目录资料的废弃与删除由维护者确认，并先评估已分发给外部的副本影响，不按内部"未引用草稿"规则清理。

## 新增与更新规则

1. 命名：使用可读的主题文件名；演示、对接文档、模板与工具分别放 `demos/`、`integration/`、`templates/` 等分组子目录，不直接堆在根目录。
2. 每个资源在索引登记后才算交付；更新内容时同步"更新时间"，分发方式或版本变化时在用途列补充说明。
3. 入口统一使用仓库相对链接；对外分发使用导出或打包时，导出规则写在本目录 README 或对应资源内。
4. 废弃先在索引中标注状态，由维护者确认后再删除文件。

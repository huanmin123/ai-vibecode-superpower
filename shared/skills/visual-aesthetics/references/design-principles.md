# 视觉组织通用原理

布局、色彩、搭配三个维度的组织手段，均为跨场景原理，不落具体场景做法。具体数值标准（如 WCAG 对比度阈值）属于各自语境；"明度差必须足够"是通用的。

## 布局

- **视觉层级四杠杆**：尺寸、重量（粗细/深浅）、位置（动线起点）、隔离度（周围留白越多越显眼）。编码重要性只有这四个手段，用尽即止。
- **邻近性（格式塔）**：关系用距离表达，放得近 = 有关；这是最原始也最有效的分组手段，不需要任何装饰。
- **对齐**：一切元素应对齐到某物。数学对齐之外还有光学对齐——圆形、三角形需要少量越出基线，看起来才齐。
- **网格与比例**：网格提供共同参照系；比例系统（黄金比、√2、模数阶）的价值不在具体比值，而在"尺寸来自一个成体系的小集合"，杜绝随手乱设。
- **留白是内容**：分组、强调、节奏都靠留白实现。留白不是没画满，是主动的组织手段。
- **平衡**：对称 = 稳定、正式；不对称 = 动态、现代，但视觉重量须补偿。判定方法：眯眼看成团的明暗色块是否站得稳。
- **焦点**：存在单一主要目标时，设置一个第一焦点并安排次级信息；多个并列主要目标时，按任务关系组织并保持可比较，不人为制造优先级。
- **动线**：具体扫视路径依赖文化阅读习惯，不钉死；不变的原则是——显著性的空间排序必须等于重要性排序。

## 色彩

- **三属性**：色相 hue、饱和度 saturation、明度 value。所有色彩判断拆到这三轴上谈。
- **明度优先**：把画面变灰后仍应成立——层级与可读性由明度承载，色相负责语义与性格。灰度测试是色彩健康的第一检查。
- **相对性（Albers）**：颜色没有绝对的样子，只有"在某邻域中的样子"；同一颜色换背景即变样。判定颜色永远在最终背景上看。
- **角色**：主导色（大面积，低饱和或中性）、次级色（支撑主导）、强调色（最小面积、最高对比，只给最重要的东西——强调色到处都是 = 没有）、中性阶（文字与表面，占大头）、语义色（遵循危险/成功/警告等约定，不自创）。"60-30-10"是主导-次级-点缀面积律的一种表达，不是硬公式。
- **数量纪律**：色相 ≤ 3 起步；大面积低饱和，小面积允许高饱和；色相越少越稳。
- **和谐方案**（色彩间的关系，不是具体色值）：单色系（同色相拉明度/饱和度，最安全）、邻近（相邻色相，和谐且有丰富度）、互补（对边色相，最大张力，面积须悬殊才不吵）、三角（等距三色，活泼但难控，须明显的明度主从）。共同结构：**大面积低差异 + 小面积高对比**。
- **对比度是功能属性**：前景与背景的明度差决定可读性。
- **色彩心理只有弱趋势**：蓝→冷静信任、红→紧迫热烈、绿→自然安全、黄→明快警示……且文化依赖。当倾向参考，不当规则用。

## 搭配

- **总纲：重复造统一，对比造趣味**。统一来自重复——同类元素永远同待遇（同样的间距逻辑、同样的圆角逻辑、同一套图标风格）；趣味来自受控对比——每个对比都应有理由（层级或语义），无理由的变化就是噪。
- **对比要单纯**：同类同级元素互相区分时只动一个维度——想用大小对比就只用大小。多维度混着变，读者读不出"为什么不同"，只剩下乱。层级编码不受此条限制：同一处层级由尺寸 + 字重 + 颜色共同承载同一个重要性动机（见字体搭配），动机单一，不算混变。为满足可访问性而冗余传达状态时也不受此限制，例如颜色同时配合图标或文字。
- **来源纪律**：字体族 ≤ 2；图标一套（线性就全线性）；图片统一色调处理；阴影/描边表达层级要成体系，不能每个元素自己决定。这些默认值是起点而非硬上限：品牌规范、图片保真（记录真实色彩的图像不得为色调统一而改）、数据可比性与字体回退等任务约束优先。
- **字体搭配**：一套字体 + 多字重常常胜过多族混排；两族搭配须差异明显——两款相似的无衬线互搭（微差）是最丑的组合。层级靠尺寸 + 字重 + 颜色三件套。
- **相似元素的差异只动一个维度**：同一排同类元素要变化时，只变内容或只变一处强调；为满足可访问性而冗余传达状态时，按上一条执行。
- **装饰与信息争夺同一资源**（注意力）：信息密度越高的区域，装饰越要退后。
- **微差警戒**：一切"差一点"——差 1px 的对齐、相似但不同的间距、几乎一样的两种灰——比明显的差异更伤质感。原则：**要么一致，要么明显不同**。

# 视觉美学

美的工作定义是**形式、内容与情境之间恰当而有表现力的关系**。表达可以服务功能、理解、情感、气质或文化意味；根据需求、内容、受众、媒介和限制选择目标。选择有理由不代表效果已成立。不设定固定风格，也不承诺普遍的美。

按此顺序工作：**明确意图 → 组织关系 → 结合情境取舍 → 观察效果**。六条方法是可选择的思考提示，不是规则、评分项或完整的中国美学理论：

| 方法 | 操作提示 | 边界 |
| --- | --- | --- |
| **以意统形** | 要表达什么？每项形式选择如何支持它？ | 遵循用户目标，不补入默认风格。 |
| **虚实相生** | 哪些内容应呈现、强调、留白或暗示？ | 留白不能隐藏用户要求或理解所必需的信息。 |
| **疏密有致** | 信息和注意力应在哪里聚集、在哪里舒展？ | 内容和任务需要时可以高密度。 |
| **气韵贯通** | 哪些节奏、呼应或动势构成预期气质，实际效果是否可观察？ | 指明具体元素与关系；单说“缺少气韵”不是证据。 |
| **变化有度** | 什么建立连贯，什么差异表达内容、层级或节奏？ | 细微变化也可能成立；有意图不等于效果成立。 |
| **因境制宜** | 内容、受众、媒介和限制如何影响表达选择？ | 不把情境变成固定风格模板。 |

除非用户明确允许编辑，否则保留用户提供的原文、事实和数据。审美意图不能豁免用户约束或必要可读性。本 skill 提供方法与评审依据，不要求增加角色、工具、评分字段或强制机制；执行范围服从当前任务授权。

## 评审结果

检查所有提供的同类产物，并在适用时检查彼此的一致性。沿用以下五步观察和 11 个维度；每项都按任务意图与验收要求判断，不能仅因输入媒介而跳过。真正不适用的项目需说明理由；必要证据缺失应标为 **Unverified**，不能改成“不适用”。

1. **一瞥：**注意首先落在哪里？这是否支持预期理解或感受？
2. **眯眼：**弱化细节后，预期关系、节奏或氛围是否仍可感知？均匀本身不等于失败。
3. **灰度：**仅在颜色承担必要层级或区分时使用；只有未满足明确要求才记为违反。
4. **维度走查：**依据任务逐项观察：层级、焦点、对齐、间距、密度、对比、一致性、平衡、色彩秩序、动线和收口。各维度含义见下表。
5. **收口：**按要求和可观察结果检查细节、边缘与完成度。

| 维度 | 观察含义 |
| --- | --- |
| 层级 | 内容相对重要性是否按意图可辨。 |
| 焦点 | 注意落点是否符合意图；需要主次时检查主焦点，需要分布注意时检查其组织关系。 |
| 对齐 | 元素的对齐或错位是否支持预期的关联与区别。 |
| 间距 | 距离、留白和节奏是否支持内容关系。 |
| 密度 | 信息量是否适合内容、受众、表达目的和可读要求。 |
| 对比 | 差异是否足以辨认、承载预期关系且彼此不冲突。 |
| 一致性 | 相似与差异是否符合元素各自的内容或作用。 |
| 平衡 | 视觉力量与空缺的分布是否形成预期效果。 |
| 色彩秩序 | 色彩关系、角色与明暗是否支持表达和必要辨识。 |
| 动线 | 实际注意路径与预期理解或感受是否相符。 |
| 收口 | 边缘、细节和完成度是否符合本次要求。 |

发现已证实违反要求时，结论为 **fail**，并同时列出未知项。没有已知违反但缺少必要证据时为 **Unverified**。只有必要检查完成且没有违反时才为 **pass**。确实不适用的项目须说明理由。`pass` 只覆盖实际检查范围，不证明普遍美或保证用户喜欢。

每个已证实问题都要指出元素或关系、相关意图或约束、观察到的结果和证据。主观建议单独列出。不得用“缺少气韵”或“不够高级”等抽象判断代替证据，也不编造像素值。保留适用的可访问性要求，例如足够的对比度、状态不只靠颜色传达，以及交互场景中的焦点可见。

使用现有角色和可用工具观察渲染结果；仅根据已指出的证据定向修改，再次评审：**生成 → 观察 → 定向修改 → 复审**。提案或意图说明不能证明最终效果。

# 系统执行规范

这是执行系统命令时的通用路由入口。识别本机或远端系统、Shell 和架构一次后，按下表只读取会影响当前命令的补充文档。

| 场景 | 必读文档 | 额外条件 |
| --- | --- | --- |
| Windows 本机 | [Windows 与 PowerShell 7](windows.md) | 优先使用 PowerShell 7 语法和盘符路径 |
| macOS 本机或远端 | [macOS](macos.md) | 按实际架构和工具链执行 |
| Linux 本机或远端 | [Linux](linux.md) | 按发行版和实际包管理器执行 |
| SSH、SCP、SFTP、rsync | [SSH](ssh.md)、本地平台和目标平台文档 | 本地与远端 Shell 分开构造 |
| Windows 连接 macOS/Linux | [跨系统操作示例](跨系统操作示例.md) | 仍须读取 SSH 与目标平台文档 |
| `rg` 已确认缺失 | [ripgrep 安装](rg.md) | 安装后重新验证 |

远端操作同时读取本地平台和目标平台文档；只读网络请求不自动等同于改变外部状态，但仍须遵守访问授权，并留意受保护数据、审计或费用影响。

## 命令约定

- 路径和动态值作为独立参数并加引号；本地与远端命令各自使用目标 Shell 的语法，不依赖上一条会话的状态。
- 命令在明确且存在的工作目录执行；文件路径、文档路径和命令文本不能作为工作目录；纯版本查询或工具定位可沿用当前目录。
- 远端复杂逻辑传脚本后用明确的 `bash`、`zsh` 或项目入口执行，不堆叠本地与远端多层转义。
- 写入文件时遵循仓库既有编码、换行和文件 mode。
- 检查原生命令退出码；`rg` 返回 `0` 表示有匹配，`1` 表示无匹配，大于 `1` 表示错误。
- 只读探测无输出只代表当前权限下未发现，不等于目标不存在或命令失败；权限错误和字段缺失保留为未知。
- 只停止本任务启动且已核对命令行的进程。
- 验证深度、失败处理和状态变更授权以全局 `AGENTS.md` 为准。

# Windows 连接 macOS/Linux

读取顺序：[Windows](windows.md) -> [SSH](ssh.md) -> [Linux](linux.md) 或 [macOS](macos.md)。此模板只演示 Windows 本地 Shell 如何传递参数；连接授权、凭据边界和远端平台语法以对应文档为准，只读取会影响当前命令的部分。

用户明确指定密码、密钥、代理或其他认证方式时，按用户指定的方式连接；未指定时沿用 SSH 客户端默认配置。密码按用户提供的方式传递，终端提示或安全凭据通道通常更方便。

```powershell
$ErrorActionPreference = 'Stop'
$ssh = (Get-Command ssh.exe -ErrorAction Stop | Select-Object -First 1).Source
$target = 'user@host.example.com'
$port = 22
$sshOptions = @(
  '-p', "$port",
  '-o', 'ConnectTimeout=10'
)
```

该模板默认保留 SSH 客户端认证链；如用户指定了认证选项，可在 `$sshOptions` 中加入对应参数。

## Linux

```powershell
$remote = 'uname -srm && sed -n "1,20p" /etc/os-release && printf "login_shell=%s\nargv0=%s\n" "$SHELL" "$0" && command -v rg && rg --version'
$sshArgs = @($sshOptions + @('--', $target, $remote))
& $ssh @sshArgs
if ($LASTEXITCODE -ne 0) { throw "Linux 远端命令失败：$LASTEXITCODE" }
```

## macOS

```powershell
$remote = 'sw_vers && uname -srm && printf "login_shell=%s\nargv0=%s\n" "$SHELL" "$0" && command -v rg && rg --version'
$sshArgs = @($sshOptions + @('--', $target, $remote))
& $ssh @sshArgs
if ($LASTEXITCODE -ne 0) { throw "macOS 远端命令失败：$LASTEXITCODE" }
```

本地 PowerShell 用单引号保存远端 POSIX 命令，避免提前展开 `$SHELL`、`$0` 和管道。远端缺少 `rg` 时读取目标平台链接的 [ripgrep 安装](rg.md) 章节。

## 远端搜索

```powershell
$remote = 'cd "$HOME/project" || exit 2; rg --line-number --hidden --glob "!.git" -- "search-term" .'
$sshArgs = @($sshOptions + @('--', $target, $remote))
& $ssh @sshArgs
$exit = $LASTEXITCODE
if ($exit -gt 1) { throw "远端搜索失败：$exit" }
```

`rg` 退出码语义见 [系统执行规范](README.md#命令生命周期)。

## 上传文件

```powershell
$localFile = (Resolve-Path -LiteralPath 'D:\build\package.zip').Path
$remoteTarget = "${target}:/tmp/package.zip"
$scpArgs = @('-P', "$port", '--', $localFile, $remoteTarget)
& scp.exe @scpArgs
if ($LASTEXITCODE -ne 0) { throw "SCP 上传失败：$LASTEXITCODE" }
```

上传后的存在性、大小、哈希或应用级结果是否核对，按用户需要决定。

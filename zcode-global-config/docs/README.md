# ZCode 全局参考文档

`<ZCODE_HOME>/AGENTS.md` 是全局行为与授权入口。本目录只提供系统命令的按需路由、平台差异和工具安装说明；项目级规则、skill 和安装器行为以各自权威文件为准。

安装源文件中的 `<ZCODE_HOME>` 只用于部署前占位；安装器会在部署时替换为实际 ZCode home，已安装文档不应再包含该占位符。

## 使用方式

需要执行系统命令时，读取 [系统执行规范](system/README.md)，按当前命令涉及的平台、SSH 或工具场景选择补充文档。只读取会影响当前命令构造、执行或验证的内容，不因关键词匹配机械加载整棵目录，也不重复读取已经满足的前置条件。

ZCode 终端在 Windows 上可能使用 Git Bash（POSIX）或 PowerShell；执行命令前按系统执行规范识别实际 Shell，再选择对应的平台文档。

## 文档职责与维护

- `AGENTS.md` 只放跨项目、每次任务都有效的行为与授权边界；`docs/system/` 只放平台语法、命令、工具安装和排障。
- 每条规则只在权威入口完整说明一次。其他文件只链接并说明适用条件；技能入口只保留路由和执行约束，按任务读取参考资料。
- 新增或修改命令时，写清适用条件、预检、可核对的成功证据和失败边界；按风险保留必要的平台差异，不用抽象措辞替代可执行说明。
- 不在公开规范中保存主机地址、账号、密钥、令牌、生产连接信息或其他敏感事实。

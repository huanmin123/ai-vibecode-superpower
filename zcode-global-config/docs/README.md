# ZCode 全局参考文档

`<ZCODE_HOME>/AGENTS.md` 是全局行为与授权入口。本文件是系统命令文档的唯一入口：包含完整索引和通用命令约定，读本文件即可判断是否需要再读其他文档。

## 读取规则

1. 会话内首次执行系统命令前读本文件一次；之后沿用同一份约定，不重复读取。
2. 只使用文件读取、编辑等非命令工具的任务不触发本文件；一旦要执行系统命令（含 `rg` 搜索），先读本文件。
3. 宿主已提供本机系统、Shell 和架构时直接采用；缺失时才读对应平台文档的“识别环境”小节。
4. 只读“文档索引”中命中当前场景的文档；未命中不读，已满足的前置条件不重复读取。

ZCode 终端在 Windows 上可能使用 Git Bash（POSIX）或 PowerShell；执行命令前先识别实际 Shell，按实际 Shell 构造和验证命令。

## 通用命令约定

- 路径和动态值作为独立参数并加引号；本地与远端命令各自使用目标 Shell 的语法，不依赖上一条会话的状态。
- 命令在明确且存在的工作目录执行；文件路径、文档路径和命令文本不能作为工作目录；纯版本查询或工具定位可沿用当前目录。
- 远端复杂逻辑传脚本后用明确的 `bash`、`zsh` 或项目入口执行，不堆叠本地与远端多层转义。
- 写入文件时遵循仓库既有编码、换行和文件 mode。
- 检查原生命令退出码；`rg` 返回 `0` 表示有匹配，`1` 表示无匹配，大于 `1` 表示错误。
- 只读探测无输出只代表当前权限下未发现，不等于目标不存在或命令失败；权限错误和字段缺失保留为未知。
- 只停止本任务启动且已核对命令行的进程。
- 验证深度、失败处理和状态变更授权以全局 `AGENTS.md` 为准。

# 项目文档

`docs/` 保存可提交的稳定设计、边界、验收标准和维护说明。真实开发、测试、生产环境事实、凭据、日志和发布产物不放在这里；如后续确有需要，使用被 Git 忽略的 `.local/project-resources/` 保存私有事实。

## 适用范围

- 多代理工作流、角色路由和安装行为继续以根目录 `AGENTS.md`、`plugins/agnets-workflow/` 和安装脚本为准；本目录不复制这些细节。
- 稳定架构和接口约束放在本目录；一次性实施拆分、进度和执行记录放在 `plans/`，只有确有持续维护价值时才新增该目录。
- 文档默认使用简体中文；代码、命令、路径、配置键、协议字段和插件标识保留原文。
- 不把设想中的功能写成已实现事实；状态、待确认项和验证证据必须明确区分。
- 不在公开文档中写入真实凭据、主机地址、连接串、生产日志或其他私有环境事实。

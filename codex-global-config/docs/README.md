# Codex 全局参考文档

## 读取顺序

`<CODEX_HOME>/AGENTS.md` 是全局行为入口。安装器会把本文和全局 `AGENTS.md` 中的 `<CODEX_HOME>` 替换为本机绝对路径；已安装文档不应再包含此占位符。项目中更具体的 `AGENTS.md`、项目文档和自动化入口优先，但不能降低平台安全策略或用户明确限制。

需要执行系统命令时，先读 [系统执行规范](system/README.md)；该入口定义平台、SSH 和工具安装的精确读取路线。不要无目的加载整棵文档树，也不要为同一任务重复读取已满足的文档。

## 文档职责与维护

- `AGENTS.md` 只放跨项目、每次任务都有效的行为与授权边界。
- `docs/system/` 只放平台语法、命令、工具安装和排障；稳定规则与一次性实施计划分开。
- 每条规则只在权威入口完整说明一次。其他文件只链接并说明适用条件；技能入口只保留路由和执行约束，按任务读取参考资料。
- 新增或修改命令时，写清适用条件、预检、可核对的成功证据和失败边界；保留必要的平台差异，不用抽象措辞替代可执行说明。
- 不在公开规范中保存主机地址、账号、密钥、令牌、生产连接信息或其他敏感事实。

# Codex 全局参考文档

## 读取原则

- `~/.codex/AGENTS.md` 是始终生效的核心行为规范；本目录只按当前任务需要读取，不得无目的遍历。
- 执行本机或远端系统命令前，按[系统执行规范](system/README.md)只加载对应平台和传输协议文档。
- 项目内更具体的 `AGENTS.md`、项目文档和自动化入口优先；平台安全策略与用户明确要求不可被降低。

## 维护规则

- 只有跨项目、每次任务都必须遵守的 AI 行为进入 `AGENTS.md`。
- 平台语法、命令、工具安装和排障只进入对应系统文档；稳定规则与一次性实施计划分开。
- 对同一行为只在其权威入口写一次；其他文件链接或说明适用条件，不复制全文。技能入口只写路由和约束，任务命中时再读取对应参考资料。
- 每项规则应说明适用条件、预检或前提、用户可核对的成功证据，以及失败时的处理边界；不要以抽象的“已优化”或“按需处理”替代可执行说明。
- 新增命令时同时写明适用条件、预检、成功证据和失败处理；删除失效命令时同步更新入口与示例。
- 不在公开规范中保存主机地址、账号、密钥、令牌、生产连接信息或其他敏感事实。
